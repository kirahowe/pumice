pumice

Your Obsidian vault, in Emacs.

An Emacs package for working in an Obsidian vault without running Obsidian. Your notes stay plain Markdown with [[wikilinks]], right where they are, and pumice adds nothing of its own to the vault.

(use-package pumice
  :vc (:url "https://github.com/kirahowe/pumice")
  :defer t
  :init
  (pumice-global-mode 1)
  (keymap-global-set "C-c n" 'pumice-command-map))

Free software (GPL-3.0-or-later). Emacs 29.1 or later, and no other dependencies.

Features

  • Jump to any note

    Find a note by name or alias. If nothing matches, pumice starts a new note in the folder your vault uses for new notes.

  • Links that resolve like Obsidian's

    Follow [[Note]], [[Note#Heading]], [[Note|text]], ![[embeds]] and Markdown links. Each link is coloured by whether it resolves, even when two notes share a name.

  • Completion

    Note names after [[, headings after [[Note#, and tags after #.

  • Backlinks panel

    A side panel that follows the note you're in: lines that link to it, lines that mention it without linking (one key makes them links), and its outgoing links.

  • Daily notes

    Your vault's own folder, date format and template. Open today, yesterday, tomorrow or any date, step between daily notes, or log a timestamped line without leaving the buffer you're in.

  • Renames that keep links working

    Rename or move a note and every link to it is rewritten. Extract a region into a note of its own, or move a note to the vault's .trash.

  • Folder tree, tags and search

    Browse the vault in a side window, pick a note by tag (nested tags and frontmatter tags included), or search the text of every note.

  • Templates and pasted images

    Insert templates that use {{title}}, {{date}} and {{time}}. Paste an image from the clipboard and it's saved and named as Obsidian would.

Shares the vault with Obsidian

Pumice reads each vault's .obsidian settings to learn where daily notes, templates, new notes and attachments go. Obsidian on your phone or another computer keeps working on the same files.

  • Pumice never writes to .obsidian and never adds a cache or an index to the vault. Its index lives in memory.
  • If Obsidian has run on this computer, pumice finds your vaults on its own. Otherwise, list them in pumice-vault-directories. A plain folder of Markdown works too.
  • Links it writes use the note's name when that's unambiguous, and its path when it isn't. Deleted notes go to .trash.

The name comes from the rock: pumice is the same volcanic glass as obsidian, with most of the weight taken out.

A command line for scripts and agents

bin/pumice runs the same index in a batch Emacs. It doesn't need a running Emacs or a running Obsidian, and it doesn't read your init file.

List results come one per line, with paths relative to the vault root, or as JSON with --json. pumice help lists every command.

A coding agent can read and change your notes through it. The repository includes a skill for Claude Code, and the README has a snippet for any agent's AGENTS.md.

On a synthetic vault of 5,000 notes, a cold pumice backlinks takes 0.9 seconds. On a real vault of 291 notes, a command takes 0.3.

# notes tagged project, still active
pumice list --tag project --where status=active
pumice backlinks "Weekly Review"
pumice tasks --folder Projects

# path of today's note, created if missing
pumice daily
pumice log "Sent the invoice"

pumice new "Title" --template "Meeting" --stdin < body.md
pumice set "Some note" status=done

# rewrites every link to the note
pumice rename "Old name" "New name"

# links that lead nowhere
pumice unresolved

Install

Emacs 30 or later

Add this to your init file. It installs the latest release; add :rev :newest after the URL to follow the main branch instead.

(use-package pumice
  :vc (:url "https://github.com/kirahowe/pumice")
  :defer t
  :init
  (pumice-global-mode 1)
  (keymap-global-set "C-c n" 'pumice-command-map))

Pumice doesn't bind pumice-command-map to any key, so C-c n is only a suggestion. Install markdown-mode too if you want Markdown highlighting.

Emacs 29

Run M-x package-vc-install, enter https://github.com/kirahowe/pumice, and add the two lines from :init above to your init file. Without a package manager, clone the repository, add it to load-path, and (require 'pumice) before those lines.

Then try it

With the map on C-c n: C-c n d opens today's daily note, C-c n n jumps to a note or starts one, and C-c n a logs a line to today's note. If Obsidian has never run on this computer, name your vault first:

(setq pumice-vault-directories '("~/Notes"))

The command line

Link the script onto your PATH from the installed package (or from a clone, if you only want the command line):

mkdir -p ~/.local/bin
ln -s ~/.emacs.d/elpa/pumice/bin/pumice ~/.local/bin/pumice
pumice vaults

If your Emacs directory is ~/.config/emacs, the package is under ~/.config/emacs/elpa/pumice. On a computer without Obsidian, set PUMICE_VAULT in your shell profile.

Evil and Spacemacs

Vim keys are opt-in with (require 'pumice-evil). A Spacemacs layer in contrib/spacemacs/pumice puts the commands under SPC a N.

The README has every key, the optional packages pumice uses when they're installed, and how to keep Emacs's backup files out of the vault.

What it doesn't do

Pumice doesn't render embeds or Markdown inline, draw a graph, run Obsidian plugins, or sync anything. Dataview queries, canvases and .base files appear as files you can link to, not as Obsidian would draw them. Frontmatter is read as the flat properties Obsidian writes, not as arbitrary YAML.
